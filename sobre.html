Sobre o projeto

Aurora Creature · projeto de estudo

Este jogo foi feito exclusivamente para fins de estudo. É um projeto pessoal de portfólio para praticar TypeScript, Canvas 2D, Web Audio, arquitetura orientada a objetos, Git Flow e CI/CD. Não tem nenhum fim comercial: não há anúncios, doações, venda nem coleta de dados.

Conteúdo original

Todas as criaturas, golpes, tipos, personagens, cidades e rotas foram criados para este projeto. A arte é desenhada por código (as sprites das criaturas são geradas a partir de uma semente) e os efeitos sonoros e as músicas são sintetizados no navegador. O jogo não usa imagens, sons, nomes ou personagens de nenhuma franquia existente.

O que foi estudado

  • TypeScript em modo strict e arquitetura orientada a objetos;
  • renderização em Canvas 2D com pixel art e geração procedural de sprites;
  • síntese de som e música com a Web Audio API;
  • fluxos de jogo com async/await e pilha de cenas;
  • persistência com localStorage em 3 slots de save;
  • internacionalização (português e inglês);
  • Git Flow com Pull Requests, Conventional Commits, CI no GitHub Actions e deploy no GitHub Pages.

About the project

Aurora Creature · study project

This game was made exclusively for study purposes. It is a personal portfolio project to practice TypeScript, Canvas 2D, Web Audio, object-oriented architecture, Git Flow and CI/CD. It has no commercial purpose: no ads, donations, sales or data collection.

Original content

All creatures, moves, types, characters, towns and routes were created for this project. The art is drawn by code (creature sprites are generated from a seed) and the sound effects and music are synthesized in the browser. The game does not use images, sounds, names or characters from any existing franchise.

What was studied

  • TypeScript in strict mode and object-oriented architecture;
  • Canvas 2D rendering with pixel art and procedural sprite generation;
  • sound and music synthesis with the Web Audio API;
  • game flows with async/await and a scene stack;
  • persistence with localStorage in 3 save slots;
  • internationalization (Portuguese and English);
  • Git Flow with Pull Requests, Conventional Commits, CI on GitHub Actions and deploy to GitHub Pages.
